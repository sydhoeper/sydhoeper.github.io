Unity · VR class project · 2025

Flight of the Honeybee

A VR game following one honeybee task: collect nectar, return to the hive, and pass it to other bees.

RoleSolo designer + developer
FormatVR game
Core loopForage, return, and exchange
Result100% class grade

The game loop

One trip from the landscape to the hive, with a clear goal at every stage.

  1. 01

    Fly

    Navigate the environment.

  2. 02

    Collect

    Gather nectar from flowers.

  3. 03

    Return

    Carry it back to the hive.

  4. 04

    Exchange

    Shoot nectar spheres to other bees.

What I built

Movement, collection, two environments, and a final exchange connected into one VR sequence.

Movement

Bee-scale flight

Direct bee control makes navigation the foundation.

Progress

Nectar collection

Flowers turn exploration into a clear task.

Completion

Hive exchange

Nectar spheres create a distinct final action.
