Campendium · 2023

Map Overlay Redesign

Helping RVers efficiently explore, compare, and navigate map overlays.

Overview

Campendium split map layers across three buttons and four drawers. Adding a smoke layer exposed the need for one scalable system.

Context

Map layers had become fragmented and difficult to extend.

Objective

Simplify selection, support Pro conversion, and accommodate future layers.

Challenge

Make multiple layers easy to select, compare, and change.

My role

I led the project from early concepts through developer handoff.

Challenges and opportunities

The system needed to reduce confusion and organize free and Pro tools.

Audience
Challenges
Opportunities
Customer
  • The existing experience was disjointed
  • Adding another control would create more clutter and confusion
  • Consolidate every map layer into one view
  • Make it easier to compare and combine overlays
Business
  • There was no clear place for the new smoke layer
  • The unclear design made feature upsells more difficult
  • A more efficient selection experience could support Pro conversion
  • A scalable system would make future additions easier

Approach

I worked mobile-first, then adapted the strongest direction across devices.

High-level strategy

Resolve the smallest screen first, then scale the interaction up.

Methodologies

Human-centered design within a lean product framework.

Collaboration

Frequent product, engineering, and design reviews.

Process

Research narrowed the problem; wireframes and UI iteration shaped the final system.

Proposed solution

One drawer organizes base maps and overlays across mobile and desktop.

Design decisions

Familiar behavior, clearer grouping, and visible selection states shaped the final system.

View 7 design decisions Hide design decisions ⌄
Drawer pattern

Keep behavior users already understand

The existing drawer already supported scrolling, varied screen heights, and thumb-friendly use.

Tile pattern

Make options visual and easy to tap

Image-and-text tiles preview each overlay and provide large tap targets.

Information architecture

Use categories to reduce cognitive load

Familiar categories make a growing collection easier to scan.

Base maps

Make single selection unmistakable

Distinct selected and unselected states clarify the active base map.

Overlays

Support multiple simultaneous selections

Checkboxes show that multiple overlays can be active at once.

Selection feedback

Keep the current state visible

A count pill keeps the number of active overlays visible.

Bulk action

Reveal “Clear All” only when it is useful

The action appears only when users have something to clear.

Outcomes and impact

The redesign launched as one clearer, more scalable system for Campendium’s map tools.

Launched outcome

One control made the map easier to use—and easier to grow.

RVers could compare and combine map context without bouncing between disconnected controls. Campendium gained a clearer surface for Pro features and future layers.

User
One drawer made layers easier to find, combine, review, and clear.
Business
The team reported stronger engagement and Pro conversion after launch; exact figures were not retained.
Product
Future maps, overlays, and access states gained a reusable framework.

Leadership takeaway: Connecting each interaction decision to customer comprehension and product scalability made the case for one unified system.
